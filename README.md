## 已完成部分

1. 扩展地图
2. 添加了一些 `Area2D` 的脚本：
   - 玩家可以获得金币
   - 用跳板起跳
   - 爬梯子
   - 踩到尖刺或掉入虚空会被送回重生点
3. 增加冲刺功能，按 `Shift` 冲刺
4. 限制了飞行能力，单次只能飞行0.5秒，且有10秒的冷却时间
5. 加入终点，到达后结束游戏并结算
6. 加入简单的结算界面，记录获得金币数量和死亡次数
